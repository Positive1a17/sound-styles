# Звуковые стили

16 стилей звука для роликов: 12 паков UI-звуков [uisfx](https://www.npmjs.com/package/uisfx) (используются скиллом Real SFX, CC0) и 4 пресета [earshot](https://github.com/Leonxlnx/earshot) (MIT). У каждого стиля картинка с волнами звуков и кнопки, чтобы послушать.

Страница: https://positive1a17.github.io/sound-styles/

Звуки uisfx — CC0 1.0. Звуки earshot отрендерены из его банка (MIT; записи-источники CC0, см. CREDITS_FIT в репозитории earshot).
